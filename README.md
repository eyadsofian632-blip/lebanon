# ELBAKRI OVERSEAS — رحلة لبنان 🇱🇧

صفحة هبوط (Landing Page) لرحلة لبنان الجماعية — من 2 إلى 7 سبتمبر · 6 أيام / 5 ليالي.

عربي · RTL · Mobile-first · بدون أي build step.

---

## التشغيل محليًا

الموقع HTML/CSS/JS خالص — مفيش تنصيب ولا مكتبات.

```bash
npx serve .
# أو
python3 -m http.server 8000
```

وافتح `http://localhost:8000`.

> افتحه من خلال سيرفر مش بالدبل كليك على الملف — المسارات مطلقة (`/assets/...`).

---

## الرفع على Vercel

1. ادخل [vercel.com/new](https://vercel.com/new) واختار الريبو ده.
2. **Framework Preset:** `Other`
3. **Build Command** و **Output Directory:** سيبهم فاضيين
4. اضغط **Deploy**.

`vercel.json` فيه هيدرز الكاش والأمان جاهزة.

## ربط دومين من GoDaddy

### 1) ضيف الدومين في Vercel

في المشروع → **Settings** → **Domains** → اكتب دومينك → **Add**.
Vercel هيديك القيم اللي تحطها في GoDaddy.

> الموقع ده متربوط دلوقتي على **`lebanon.elbakrioverseas.com`**.

### 2) ظبّط الـ DNS في GoDaddy

ادخل [dcc.godaddy.com](https://dcc.godaddy.com) → دومينك → **DNS** →
**Manage Zones**، وحط دول:

| Type | Name | Value | TTL |
|---|---|---|---|
| `A` | `@` | `76.76.21.21` | 600 |
| `CNAME` | `www` | `cname.vercel-dns.com` | 600 |

> لو لقيت `A` أو `CNAME` قديمة على `@` أو `www` (بيحطها GoDaddy لصفحة
> «Parked»)، **امسحها** — لو سيبتها الدومين هيفضل يودّي على صفحة جودادي.

**لو بتستخدم ساب دومين** (زي `lebanon.elbakrioverseas.com`) بدل الدومين
الأساسي، محتاج `CNAME` واحد بس — مش سجل `A`:

| Type | Name | Value |
|---|---|---|
| `CNAME` | `lebanon` | `cname.vercel-dns.com` |

في خانة Name اكتب الجزء الأول بس (`lebanon`)، جودادي بيضيف باقي الدومين لوحده.

**ولو Vercel قال «Verification Required»** وظهر تحذير إن الدومين مربوط بحساب
Vercel تاني، هتحتاج كمان سجل `TXT` اسمه `_vercel` بالقيمة اللي Vercel بيعرضها
في **View DNS configuration**. من غيره الدومين مش هيتفعّل مهما استنيت.

اعتمد على القيم اللي Vercel نفسه بيعرضها لو اختلفت عن الجداول دي.

### 3) استنى الـ DNS

عادة من 10 دقايق لساعة، وممكن توصل 48 ساعة. لما يخلص، Vercel هيعمل شهادة
SSL أوتوماتيك. تقدر تتابع الحالة من نفس صفحة **Domains**.

### 4) ⚠️ حدّث الدومين في الكود — خطوة مهمة

بعد ما الدومين يتفعّل، غيّره في الكود بأمر واحد:

```bash
node scripts/set-domain.mjs your-domain.com
git add -A && git commit -m "Point the site at the live domain" && git push
```

بيصلح الـ canonical ووسوم `og:` و `twitter:` والـ structured data و
`robots.txt` و `sitemap.xml` مرة واحدة.

**ليه دي مهمة؟** وسوم `og:` لازم تبقى لينك كامل. لو سيبتها على دومين Vercel
القديم، لما حد يشارك اللينك على فيسبوك أو واتساب الصورة والعنوان ممكن ما
يظهروش أو يودّوا على الدومين الغلط — وده مباشرة بيأثر على إعلانات ميتا.

## الصور

**كل الصور من صور العميل** — 17 مزار + الفندق + اللوجو + الرحلات السابقة +
صورة المشاركة. مفيش أي صورة ستوك.

عايز تغيّر صورة؟ استبدل الملف في مكانه وخلاص، مفيش تعديل في الكود.
المسارات كلها في **[IMAGES.md](./IMAGES.md)**.

`scripts/fetch-images.mjs` معطّل لكل الأماكن، فمش هيكتب فوق أي صورة لو اتشغل.

أي صورة ناقصة بتتحول تلقائيًا لبلوك أنيق مكتوب عليه اسم المكان — الصفحة عمرها ما هتتكسر.

## ملاحظات على المحتوى

الصفحة مبنية على البيانات المؤكدة بس. **مفيش**:

- آراء عملاء مُختلقة
- عدادات وقت وهمية أو «باقي 3 أماكن»
- خصومات وهمية
- أرقام تليفونات أو عناوين أو لينكات سوشيال غير حقيقية
- مرافق فندق مش متأكدين منها

قسم **آراء عملائنا** فيه 10 تقييمات حقيقية من Google بنصها الحرفي وأسماء
أصحابها ونجومهم زي ما هي. مفيش تقييم إجمالي مكتوب لأن اللي اتشاف كان جزء من
القائمة مش كلها.
