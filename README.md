# ELBAKRI OVERSEAS — رحلة لبنان 🇱🇧

صفحة هبوط (Landing Page) لرحلة لبنان الجماعية — من 2 إلى 7 سبتمبر · 6 أيام / 5 ليالي.

عربي · RTL · Mobile-first · بدون أي build step.

---

## التشغيل محليًا

الموقع HTML/CSS/JS خالص — مفيش تنصيب ولا مكتبات.

```bash
npx serve .
# أو
python3 -m http.server 8000
```

وافتح `http://localhost:8000`.

> افتحه من خلال سيرفر مش بالدبل كليك على الملف — المسارات مطلقة (`/assets/...`).

---

## الرفع على Vercel

1. ادخل [vercel.com/new](https://vercel.com/new) واختار الريبو ده.
2. **Framework Preset:** `Other`
3. **Build Command:** سيبه فاضي
4. **Output Directory:** سيبه فاضي (الروت)
5. اضغط **Deploy**.

`vercel.json` فيه هيدرز الكاش والأمان جاهزة.

### بعد أول Deploy

غيّر الدومين في 3 أماكن (دلوقتي مكتوب `https://elbakri-lebanon.vercel.app`):

- `index.html` → `<link rel="canonical">` + وسوم `og:` و `twitter:`
- `robots.txt`
- `sitemap.xml`

## الصور

```bash
node scripts/fetch-images.mjs                          # كل صور المزارات
npm i sharp && node scripts/prepare-logo.mjs <اللوجو>  # شيل خلفية اللوجو
```

الأمر الأول بينزّل 17 صورة من ويكيميديا كومنز في أماكنها الصح ويكتب
`CREDITS.md` بحقوق كل صورة. التاني بيشيل خلفية اللوجو من غير ما يمس الرسمة.

باقي على صور الفندق ورحلاتك السابقة وصورة المشاركة — دي من عندك.
التفاصيل الكاملة في **[IMAGES.md](./IMAGES.md)**.

أي صورة ناقصة بتتحول تلقائيًا لبلوك أنيق مكتوب عليه اسم المكان — الصفحة عمرها ما هتتكسر.

## ملاحظات على المحتوى

الصفحة مبنية على البيانات المؤكدة بس. **مفيش**:

- آراء عملاء مُختلقة
- عدادات وقت وهمية أو «باقي 3 أماكن»
- خصومات وهمية
- أرقام تليفونات أو عناوين أو لينكات سوشيال غير حقيقية
- مرافق فندق مش متأكدين منها

قسم آراء العملاء بيعرض دلوقتي صور حقيقية من رحلات سابقة. لما تبعت سكرين شوتس
حقيقية، حطها في `assets/reviews/`.
